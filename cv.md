## Пример кода
Codewars задание "Pete, the baker"

```
function cakes(recipe, available) { 
  const result = [];
                
  for (let item in recipe) {
    if (item in available) {
      const n = Math.floor(available[item] / recipe[item]);
      result.push(n);
    } else {
      return 0;
    }
  }
  
  return result.reduce((min, item) => (min &lt; item) ? min : item);
}
```
